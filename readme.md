## Quick start

Unzip everything, run **Wiz Codex Setup.exe**, then open **WizCodex.exe**. Load a save in the Steam game and Wiz Codex connects on its own.

Use 🌐 to switch languages. For enemy HP, turn on **Enemies** in Settings.

### 日本語

ZIPを全部展開して **Wiz Codex Setup.exe** を実行。**WizCodex.exe** を開いてゲームでセーブを読み込むと、自動でつながります。

🌐 で日本語に切り替え。敵HPは設定の「敵」をオンにすると見られます。

<details>
<summary>Setup notes / インストールの補足</summary>

Windows x64, Edge WebView2 Runtime and .NET Framework 4.6.2+ are required. Python is included. Setup is unsigned. When updating, close Wiz Codex and select its current install folder.

更新するときはWiz Codexを閉じて、今のインストール先を選んでください。

</details>
